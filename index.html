📖 免费 API 申请详细教程

Google Gemini API - 推荐新手

特点：免费额度最慷慨，每天1500次请求，无需信用卡

获取步骤：

  1. 访问 Google AI Studio
  2. 使用 Google 账号登录
  3. 点击左侧菜单 "Get API key"
  4. 点击 "Create API key" 创建新密钥
  5. 复制 API Key 并在左侧配置

API 格式：

Base URL: https://generativelanguage.googleapis.com
Model: gemini-1.5-flash, gemini-2.0-flash, gemini-1.5-pro

免费额度： 1500请求/天，100万tokens/分钟

Groq API - 速度最快

特点：响应速度极快，支持Llama 3.3 70B

获取步骤：

  1. 访问 Groq Console
  2. 使用 GitHub 或 Google 账号登录
  3. 进入 API Keys 页面
  4. 点击 "Create API Key" 创建
  5. 复制并配置到左侧

API 格式：

Base URL: https://api.groq.com/openai/v1
Model: llama-3.3-70b-versatile, mixtral-8x7b-32768, gemma-2-9b-it

免费额度： 30请求/分钟，14400请求/天

OpenRouter - 模型最全

特点：聚合100+模型，统一接口，含多个免费模型

获取步骤：

  1. 访问 OpenRouter
  2. 使用 GitHub 或 Google 登录
  3. 在 Models 页面选择免费模型
  4. 进入 API Keys 创建密钥
  5. 复制并配置

免费模型：

meta-llama/llama-3.1-8b-instruct:free
mistralai/mistral-7b-instruct:free
google/gemma-2-9b-it:free
cognitivecomputations/dolphin3.0-r1-mistral-24b:free

免费额度： 每天50次请求（免费模型）

Mistral API - 欧洲合规

特点：每月10亿tokens，GDPR合规

获取步骤：

  1. 访问 Mistral Console
  2. 注册账号（需手机验证）
  3. 进入 API Keys 创建
  4. 复制并配置

API 格式：

Base URL: https://api.mistral.ai/v1
Model: mistral-large-latest, mistral-small, codestral

免费额度： 10亿tokens/月（限速1请求/秒）

Cohere API - RAG最强

特点：RAG应用首选，Command R+性能强大

获取步骤：

  1. 访问 Cohere
  2. 注册账号
  3. 进入 Dashboard > API Keys
  4. 创建并复制 Key

API 格式：

Base URL: https://api.cohere.ai/v1
Model: command-r-plus, command-r, command

免费额度： 1000请求/月
